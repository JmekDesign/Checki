_Последнее обновление: 2026-03-23_

---

## Юридическая база

- **Юрлицо:** Грузинский ИП
- **Банк:** TBC Bank
- **Валюта продаж:** GEL (грузинский лари)

---

## Платёжная система

### Выбор: TBC E-Commerce

**Почему TBC:**
- У нас уже есть счёт в TBC → упрощённый онбординг
- REST API + OAuth2, документация нормального качества
- Поддерживает recurring payments (токенизация карты) — нужно запросить отдельно
- 2% комиссия с грузинских карт (+ 30 GEL/мес минимум)

**Ссылки:**
- Регистрация мерчанта: https://tbcpayments.ge/order/ecom/3/1
- Документация: https://developers.tbcbank.ge/docs/checkout-api-overview
- Панель мерчанта: https://ecom.tbcpayments.ge

**⚠️ Важно при регистрации:** явно указать что нужны recurring payments / card tokenization — по умолчанию не включают.

### Отклонённые варианты

| Сервис | Причина отказа |
|--------|---------------|
| Payze | Прекратили приём новых мерчантов в 2025 |
| Stripe | Грузия не в списке поддерживаемых стран |
| Ручные переводы | Не масштабируется, высокий риск ошибок |

## Модель монетизации

### Тарифы

| План | Цена | Примечание |
|------|------|-----------|
| Месячная | 49 GEL/мес | Для тех кто хочет попробовать |
| **Годовая** | **399 GEL/год** | ~33 GEL/мес, скидка ~33% — основной план |
| Ранний доступ | 299 GEL/год | Для первых ~20 клиентов, создаёт срочность |

**Почему годовая — основной план:**
- Снимает головную боль с ежемесячной оплатой
- Улучшает cash flow
- Снижает churn

### Trial

- **30 дней** бесплатно при регистрации
- Карта не требуется на этапе trial (решить окончательно)
- По истечении — предложение оплатить, затем grace period

### Grace period

- **7 дней** после истечения подписки до блокировки
- В grace period: доступ сохраняется, показывается баннер с предупреждением
- После grace period: data endpoints возвращают 402, вход в приложение возможен но без данных

---

## Что блокируется при неоплате

| Ресурс | Поведение |
|--------|-----------|
| Вход в аккаунт | Разрешён |
| Чеки, продукты, гости | 402 — заблокировано |
| Настройки venue | Разрешены (чтобы могли обновить платёж) |
| Superadmin | Не затрагивается |

## Этапы реализации

### Фаза 1 — Ручной биллинг (пока TBC не подключён)

- [ ] Добавить в venues: `trial_ends_at`, `subscription_expires_at`, `plan`
- [ ] Superadmin: кнопка Extend subscription (выбрать дату)
- [ ] Middleware: проверка статуса, 402 при истечении + grace period
- [ ] Email-напоминания: за 7 дней и за 1 день до истечения

### Фаза 2 — TBC E-Commerce (после онбординга)

- [ ] Подать заявку на мерчант-аккаунт TBC (запросить recurring)
- [ ] Страница оплаты: выбор плана → переход на TBC checkout
- [ ] Webhook от TBC → автоматическое продление `subscription_expires_at`
- [ ] Автосписание через токен карты для годовых подписок
- [ ] Страница управления подпиской в admin (отмена, смена плана)

### Фаза 3 — Реферальная программа (после биллинга)

- [ ] Реферальная ссылка → бонус на баланс
- [ ] Баланс используется при оплате подписки
- [ ] Подробнее: см. memory/project_referral.md
